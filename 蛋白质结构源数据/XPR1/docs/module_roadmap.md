# 第3.1节模块实现状态

第3.1节列的是全项目模块规划，不是进入第4节前必须写完且得到结果的清单。

| 模块 | 后续输入→输出 | 当前状态 |
|---|---|---|
| structure_registry | 结构与论文→构建体、链、突变、组装体和状态登记 | 已有技术入库与原始元数据提取；科学QC未完成 |
| family_split_guard | 家族与角色→跨集合泄漏报告 | 已检查家族与primary DOI一致性；真实角色划分和完整泄漏检查未实现 |
| state_epitope_map | 统一编号及状态→位移、SASA和局部特征 | 未实现 |
| membrane_assembly_veto | 完整组装体、膜面与候选→碰撞/不可接近否决 | 未实现 |
| counterstate_evaluator | 候选与多状态结构→状态偏好与不确定性 | 未实现 |
| pore_occlusion | 候选和孔口几何→覆盖与通路变化 | 未实现 |
| pareto_rank | 各指标及硬否决→多目标排序 | 未实现 |
| family_consensus_state_score | 多家族特征→方向一致性、效应量与区间 | 未实现 |
| ablation_report | 完整流程及等预算基线→增益、失败率与成本 | 未实现，需要后续实际结果 |

以上是接口方向，不是已验证的算法设计；当前基础脚本不能称为已完成全部自主算法。
