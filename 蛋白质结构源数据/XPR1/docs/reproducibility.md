# 数据、版本与后续运行规则

当前入口只复现本地输入检查和元数据提取，不复现生成模型或实验。每次报告记录版本、参数、运行硬件与实现文件哈希。
检查不使用随机算法；seed=0仅保留配置字段，不表示已经做过多个seed的设计试验。

## 有意更新数据

1. 保留当前Git版本及旧校验和，记录更新原因。
2. 原始结构不覆盖；新版本放入有版本名的新目录，记录URL、实际下载时间、许可、版本和哈希。
3. 更新结构表、来源记录及配置；新配置指定新的基准文件路径。
4. 显式运行snapshot创建一个不存在的新基准。旧基准不能覆盖。
5. 用新配置运行check，审核差异、结果与日志后提交。

即使只修改备注，CSV字节校验也会变化；应当保留这一版本变动的说明。
日志不要包含服务器密码、访问令牌、私人路径或不必要的身份信息。

## 后续上机门槛

GPU任务只在获准计算节点运行，不在登录节点运行大型模型。
需核实Python、CUDA、驱动、GPU显存、模型版本、权重来源及许可，完成一个真实最小模型任务，保存输入、参数、seed、作业号、日志、输出与实际用时。
本次没有登录超算、消耗GPU机时或依据截图认定软件可用。

原结构来自固定Git提交，后补资料来自2026-09-03的实际下载。两者可能不是同一次数据库发布。
标题、聚合物序列与文献一致不保证坐标修订完全相同；第4节需核查版本、链编号和坐标关系后再选择设计输入。
