# XPR1

This repository contains the valid, non-metadata files extracted from
`XPR1_project 2.zip`.

## Contents

- `data/raw/XPR1_structures/`: 51 mmCIF structure files named by their PDB
  accession IDs.
- Each structure file retains its upstream mmCIF metadata, including the
  corresponding `_entry.id`.

## Data provenance

The archive supplied structure files whose names and internal metadata identify
PDB entries. Use the accession ID in each filename to locate the corresponding
record, citation, and reuse information in the RCSB Protein Data Bank.

The supplied archive did not contain source code, model weights, notebooks,
results, logs, or populated configuration files. Empty directories and macOS
metadata (`.DS_Store` and `__MACOSX`) were intentionally omitted.

No project-specific license was included in the archive. Check the relevant PDB
record before redistribution or reuse.
